리포트 문구 편집

고친 칸은 바로 이 브라우저에 임시 저장돼요. 미리보기로 리포트에서 어떻게 보이는지 보고, 저장하고 배포를 누르면 1~2분 뒤 사이트에 반영돼요.

목록 칸은 한 줄에 하나씩. 느낌표나 이모지, 광고 말투는 문체 검사에 걸려서 저장이 안 돼요.

이 주소는 사이트 어디에도 링크가 없어요. 저장하려면 GitHub 토큰이 필요하니, 주소가 새도 문구를 바꿀 수는 없어요.

GitHub 토큰

처음 한 번만 만들면 돼요. 이 탭을 닫으면 지워져서, 새로 열 때마다 다시 붙여 넣어야 해요.

  1. GitHub 토큰 만들기 열기 (hubhub5 계정으로 로그인한 상태)
  2. Token name: 아무거나 (예: zoosa2 문구). Expiration: 90 days
  3. Repository access: Only select repositories → zoosa2
  4. Permissions → Repository permissions: Contents: Read and write, Actions: Read-only
  5. Generate token → 나온 값(github_pat_로 시작)을 복사해서 아래에 붙여 넣기

토큰은 GitHub 말고 다른 곳으로는 보내지 않아요.
