## 수법
- **따옴표 속말**: 생각을 인용부호로 그대로 꺼냄. `'이렇게까지 했는데, 잘 안 된다면...'`
- **한 겹 벗기기**: 겉으로 대는 이유 → 실제로 돌아가는 구조
- **반박 먼저 인정**: "아니라고 생각하는 분들도 계실 것 같은데요. 저도 아니었으면 좋겠습니다."
- **동네 비유**: 집 앞 카페 신메뉴, 서울역 세 시 약속, 공무원 시험 떨어지면 어떡해요
- **괄호 덧붙임**: (예시일 뿐. 실제로는 기억이 안 남), (이건 제 얘기입니다)
- **짧게 끊는 마지막 줄**: "그 반대일지도 몰라요." / "오늘의 성취는, 내일의 족쇄가 되어버립니다."
- **제목**: `주제 l 부제` (소문자 엘)
- **자기 고백**: "저도 그렇고요", "조심하려고 하는데도 반복하는 것 같습니다"

## 리딩 톤 (사주로 포장한 신점)
- 인지왜곡·CBT 용어는 앞에 안 꺼낸다. 근거는 사주로 댄다: "일지 酉를 卯가 친 해", "편관이 월지에", "인성 대운"
- 모호한 가능성 어미 금지: ~일 수 있어요 / ~하는 편이에요 / ~경향이 있어요 → 단정 과거형 "~했지요", "~했을 거예요"까지만
- 한 줄에 연도 · 계절 · 상대 · 장면 · 그때 속말을 박는다
  - 나쁨: "대인관계에서 스트레스를 받았을 수 있어요"
  - 좋음: "2019년 늦가을. 윗사람 말 한마디를 몇 주 곱씹었지요. 겉으론 '네 알겠습니다' 하고요."
